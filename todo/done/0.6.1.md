# 0.6.1

Released for Linux x86_64 and macOS arm64.

- Private windows (`private-windows`)
- A working pop-up blocker
- Window state restore (`window-state-restore`)
- Wayland clipboard for pictures, files and HTML
- Every CSS cursor
- Touch events
- Smooth wheel scrolling and touchpad fling (Linux)
- Real screen and window geometry for pages
- More context-menu entries
- Three clipboard security fixes: silent read, write without a click, password field text to the primary selection
- Idle pump at 250 ms
- Calm pages capped at 60 Hz
- Shell partial redraw
- Profile folder through a symlink
- One bad row no longer loses the session
- Semantic versions and the stable channel
- Windows parked
