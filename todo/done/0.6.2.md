# 0.6.2

Released for Linux x86_64; macOS arm64 follows.

- The surface store's tested parts: one table and one reducer for shell surfaces (hover and timed, page-attached, drag surfaces, the downloads and Spaces popups)
- Page fullscreen is per window (it used to change every window)
- The page on its own OS layer on macOS: window mode on by default, Settings, Performance, "Show pages on their own layer (macOS)" turns it off, `--page-layer=off|fullscreen|window`; measured on an M2: main process from 28 to 37 % down to 10 to 15 % during windowed video
- Overlays over a layered page blur a slowly refreshed snapshot instead of pulling the page off its layer
- A dragged item no longer sticks to the cursor after release
- The autofill offer race (a cross-origin iframe's report replaced the main frame's pending offer)
- A fresh profile opens the start page instead of a test page
- The roadmap moved to `todo/`
