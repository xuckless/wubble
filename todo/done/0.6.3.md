# 0.6.3 (released 2026-11-25, Linux and macOS, commit 554e04b)

wubble 0.6.3 brings a round of small features, smoother video on the Mac's page layer, and fixes found by a new automated check of the macOS build. Installs on either channel are offered it.

## New

- Built-in pages (Settings, the start page and the others) can be split panes, beside a website. One built-in page per split.
- Tab search (Ctrl+Shift+A, Cmd+Shift+A on macOS): every open and recently closed tab in one list.
- Chrome's keyboard shortcuts wubble was missing, and caret browsing (F7).
- Tab menu: Mute Site and New Tab Below.
- The address field's menu: Paste and Go, Copy and Edit Address, and a setting to always show full URLs.
- The reload button turns into Stop while a page loads; Shift-click reloads without the cache.
- A page that failed to load because the network was down reloads by itself when the network comes back.
- A zoom chip in the address bar when a page is not at your default zoom, with zoom in, zoom out and reset; Reset Zoom in the page menu.
- Downloads show their speed and the time left.
- Pop-up windows opened by sites can be as small as the site asks (down to 100 by 100).

## Fixes

- The first click after a drag and drop on a page no longer gets lost.
- Automatic picture-in-picture considers every pane of a split you leave, not just the focused one.
- macOS: the display's refresh rate is read correctly on ProMotion displays (120 Hz was read as 60), and again when the window moves to another display.
- macOS: a page that is not animating now reaches its own layer too (it stayed on the slower path).
- macOS: a frame dropped while the system was busy is painted again, so the page is never left a frame behind.

## Performance

- macOS, windowed 1080p60 video on an M2 Pro: 60 to 61 frames a second with the page on its layer, also with the find bar, the command bar or a menu over it (0.6.2: 54 to 55).
- macOS, one still page: the main process at 13 % of a core (0.6.2: 16 %).
- Hidden tabs, closed split panes and an unused page blur give back their GPU memory; the shell's image caches are bounded and cleaned when idle.
- Agent tabs keep accessibility updates unparsed until an agent reads the page.

## Under the hood

- Every floating part of the shell, including the command bar and the keyboard focus, now goes through one table of surfaces and one set of rules.
- A new automated macOS check runs the hand-check list on every build (`scripts/mac-checks/`).

## Known issues

- macOS: Cmd+Delete, Cmd+Left/Right and the other system editing keys do not act in page text fields yet; after Cmd+Left in a field, typing can stop until you click the field again.
- Automatic picture-in-picture on tab switch does not open yet.
- Linux: pages cost more CPU per frame than in Firefox (no page layer on Linux yet); a Linux page layer is being worked on.
- The Linux build needs a 2026 distribution (glibc 2.43); an older build base is planned.

## Platforms

Linux x86_64 and macOS (Apple Silicon; signed and notarised). Windows is parked.
